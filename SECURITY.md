# Security

## Reporting a problem

Please don't report security problems in a public issue. Instead, use
**Report a vulnerability** on the repository's
[Security tab](https://github.com/minimondocode/terminal-markdown-reader/security),
which sends it privately. Say what's affected and how to reproduce it.

You'll get a reply as soon as possible, and a fix in a new release once the
problem is confirmed.

## Supported versions

Fixes go into the latest release only.
